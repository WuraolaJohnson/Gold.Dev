// about

I like the moment a static design becomes something you can click.

My focus is turning a design — whether it's a full Figma file or a rough idea — into a working website. That means matching the details that make a design feel intentional: spacing, type, motion, and the small interactions that don't show up until you actually use the thing.

I care about building interfaces that hold up across screen sizes, write markup that makes sense to the next person who opens the file, and I'm comfortable picking up new tools when a project calls for them.

  • Design-to-code implementation
  • Responsive, mobile-first builds
  • Attention to interaction detail
  • Clean, maintainable code
